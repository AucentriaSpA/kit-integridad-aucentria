PREGUNTAS FRECUENTES

Preguntas frecuentes

¿El Kit es editable?

Sí. Los documentos están preparados para que la empresa pueda incorporar sus propios antecedentes, datos y elementos de identificación.

¿El Kit sirve para empresas que participan en Mercado Público?

Sí. El Kit está diseñado especialmente para empresas proveedoras de Mercado Público y contempla herramientas para facilitar la implementación, acreditación y gestión del Programa.

¿El Kit garantiza el cumplimiento de los requisitos de una licitación?

No. Cada licitación puede establecer requisitos específicos. El Kit entrega herramientas para implementar y respaldar el Programa de Integridad y una guía para revisar los antecedentes exigidos en cada proceso.

¿Debo mantener documentación después de implementar el Programa?

Sí. La empresa debe conservar las evidencias de implementación y realizar las actividades de mantención contempladas en el sistema.

¿Qué ocurre si nunca ha existido un caso de integridad?

El Kit contempla un Registro de Casos de Integridad que puede mantenerse disponible aunque no existan casos registrados.

¿El Kit elimina todos los riesgos de integridad?

No. Ningún sistema puede eliminar completamente los riesgos. El Kit entrega herramientas para identificarlos, gestionarlos y mantener evidencia de las medidas implementadas.
